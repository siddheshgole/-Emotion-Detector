# Final Project – Emotion Detector

## Project Name

**Final Project**

## Repository Name

**oaqjp-final-project-emb-ai**

## Project Description

This project is an AI-based **Emotion Detector** application developed using the Watson NLP library.

The application analyzes a given text and identifies the following emotions:

* Anger
* Disgust
* Fear
* Joy
* Sadness

It also determines the **dominant emotion** expressed in the input text.

## Technologies Used

* Python
* Watson NLP
* Flask
* Requests
* unittest

## Project Tasks

1. Clone the project repository
2. Create an emotion detection application using the Watson NLP library
3. Format the output of the application
4. Package the application
5. Run unit tests
6. Deploy the application using Flask
7. Incorporate error handling
8. Run static code analysis

## Application

The application provides an emotion detection function that accepts text as input and returns emotion scores along with the dominant emotion.
